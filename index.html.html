Add FitPlan to iPhone
Gmail saves HTML files in a viewer that can't install apps. Here's the exact way to get it into Safari so you can install it.
🚫
Gmail opens HTML files in its own viewer — this viewer does not have a Share button or Safari access. You need to move the file to Safari a different way.
The fix — 4 simple steps
1
Open the Gmail app → find this email
Tap the HTML attachment (the file icon that says FitPlan). It will open in a preview.
2
Tap the Share icon in the top-right corner
In Gmail's attachment preview, look for the share/export icon (box with arrow) in the top-right. Tap it.
3
Tap "Open in Safari" or "Copy to Safari"
In the share sheet look for "Open in Safari". If you don't see it, tap "More" and find Safari in the list. The file will open as a proper webpage in Safari.
4
Now install from Safari
Once open in Safari: tap the Share button ⬆ at the bottom → scroll down → tap "Add to Home Screen" → tap Add. Done.
Alternative — if Gmail doesn't show "Open in Safari"
① In Gmail, long-press the attachment → tap "Save to Files"
② Open the Files app (blue folder icon on your iPhone)
③ Find the saved HTML file → long-press it → tap "Share"
④ In the share sheet tap "Open in Safari" → then install as above
💾 Important: Open FitPlan from your home screen at least once a week. iOS erases offline storage after 7 days of inactivity.
